# SACCO execute

Inbound facility request for a pre-approved member.

```
POST /api/v1/tawarruq/execute
```

Buruuj stamps Wa'd and appoints **SEDANIA As Salam Capital** independently as wakeel, trades on AS SIDQ, vaults the trade pack and certificates, then webhooks the SACCO. The SACCO CBS pays the member. Buruuj never handles principal cash.

Bank CASA financing (muqassah, CASA credit, physical delivery) is on [SEDANIA_FINANCING.md](SEDANIA_FINANCING.md).
